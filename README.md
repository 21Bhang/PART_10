# Rate Repository App

React Native Expo app for managing software repositories and user reviews.

## Features
- Sign up / sign in
- Browse repositories with search and filtering
- View repository details with ratings and reviews
- Submit reviews and ratings

## Tech Stack
- React Native + Expo v57
- Apollo Client (GraphQL)
- Formik + Yup
- @react-native-async-storage/async-storage

## Setup
```
npm install
```

## Scripts
- `npm start` - Expo development server
- `npm android` / `npm ios` - Run on device/emulator
- `npm web` - Run in browser
- `npm test` - Run Jest tests
- `npm lint` - Run expo lint
